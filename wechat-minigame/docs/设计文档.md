# 丧尸幸存者 · 设计文档

> 微信小游戏 · 俯视生存竞技场 + 升级选卡（肉鸽）
> 文档与 `src/` 当前实现严格对齐（截至 2026-11）。

---

## 1. 产品概述

- **类型**：俯视视角、单指操作的生存肉鸽；自动战斗 + 手动走位。
- **平台**：微信小游戏（竖屏），入口 `game.js` → `src/main.js`。
- **一句话定位**：操控角色在丧尸潮中走位求生，**自动释放雷电链技能**清场，靠升级三选一卡牌越变越强，撑过 5 波即胜利。
- **当前美术**：丧尸为 3D 卡通 AI 图（离线烘焙透明 PNG），主角/伙伴为矢量二次元占位（可放 PNG 替换）。

## 2. 核心玩法

| 维度 | 说明 |
|------|------|
| 移动 | **玩家触摸/拖拽控制**（`moveTarget`），点哪走到哪，到达即停；无触摸时原地不动 |
| 攻击 | **自动释放技能**（非手动射击），冷却到即放；技能为「雷电链」 |
| 目标 | 存活并清怪，经验满自动升级；活过全部关卡 = 胜利，生命归零 = 失败可重开 |
| 节奏 | 单关 5 波次，每波 25s；敌人越往后越密越强 |
| 伙伴 | 第 3 波起自动获得 1 名 NPC 伙伴环绕助战，最多 3 名（卡牌亦可额外召唤） |

## 3. 系统架构

```
game.js(入口)
  └─ src/main.js        主循环(loop) + 资源预加载 + 触摸分发
       └─ Game          状态机 / 刷怪 / 升级选卡 / 渲染
            ├─ Player    主角：走位 + 雷电链技能
            ├─ Enemy     丧尸：朝主角移动 + 接触伤害
            ├─ Companion NPC伙伴：环绕 + 自动射弹
            ├─ Projectile 子弹（仅伙伴使用）
            ├─ Effects   程序化特效（粒子/闪电/震屏/顿帧）
            └─ loader(assets.js)  图片加载 + 去背景
  └─ src/config.js      全部数值与配色
  └─ src/skills.js      升级卡牌池
  └─ src/utils.js       数学/绘制工具
```

## 4. 游戏状态机

`Game.state` ∈ `playing | levelup | win | lose`

| 状态 | 进入条件 | 行为 | 退出 |
|------|----------|------|------|
| `playing` | 开局 / 选完卡 | 正常更新与渲染；`effects` 照常老化 | 经验满→`levelup`；过关→下一关；死亡→`lose` |
| `levelup` | 经验 ≥ 需求 | 暂停实体更新，弹出三选一卡牌 | 选卡后 `pendingLevelUps` 归零→`playing` |
| `win` | 撑过第 5 波 | 显示胜利文案 | 点击屏幕→`start()` 重开 |
| `lose` | 主角 HP ≤ 0 | 显示失败文案 | 点击屏幕→`start()` 重开 |

> 注：`update()` 在非 `playing` 状态仍调用 `effects.update(dt)`，保证闪电/粒子淡出不卡顿；命中顿帧（`hitStop`）期间冻结全部实体但保留特效动画。

## 5. 战斗系统

### 5.1 玩家技能：雷电链（核心）
- **触发**：`player.update` 中 `attackTimer` 冷却到 0 即自动释放，冷却 = `attackInterval`（0.6s）。
- **算法**（`player.js` `castLightning`）：
  1. 从玩家位置出发，在 `range`（230）内选最近敌人；
  2. 命中后，以该敌人为新起点，在 `chainRange`（180）内选最近**未命中**敌人，如此重复，最多 `chainCount`（4）跳；
  3. 每跳：画一道锯齿闪电 `effects.bolt` + 落点电火花 `effects.spark`，并对敌人 `hurt(伤害)`；
  4. 伤害逐跳衰减：`dmg *= chainFalloff`（0.82）；
  5. 至少命中 1 个时触发 `shakeAdd(5,0.12)` 与 `hitStopAdd(0.04)`（打击感）。
- **定位**：玩家是「技能攻击」而非射击——自身不发射子弹；子弹仅由伙伴产生。

### 5.2 敌人（Enemy）
- **生成**：`spawnEnemy` 从屏幕四边随机刷出。
- **AI**：朝主角直线移动；与主角重叠且 `contactTimer≤0` 时造成 `damage`（8）接触伤害，触发 `contactCd`（0.5s）冷却。
- **受击反馈**：`hurt(d, game)` 设 `hitFlash=0.14`（渲染时加色泛白）与 `stun=0.12`（短暂停止移动）；命中迸发电火花。
- **死亡**：`hp≤0` 置 `dead`，清理时 `effects.burst` 碎裂特效 + 结算经验/击杀数。

### 5.3 伙伴（Companion）
- 环绕主角做轨道运动（`orbitR=64`，角速度 1.4 rad/s），自动锁定最近敌人发射 `Projectile`（黄色弹丸，伤害 9，攻速 0.8s）。

### 5.4 子弹（Projectile）
- 仅伙伴使用；带 `hits`（穿透数）、`life`（2.2s）、`hit` 集合防重复结算；出界或寿命耗尽即销毁。
- 命中时 `e.hurt(damage, game)` 接入特效。

## 6. 升级与卡牌系统

- **经验曲线**：`xpNeeded = base(40) × ratio(1.35)^(level-1)`，取整。
- **三选一**：`rollCards` 按 `weight` 加权无放回抽取 3 张；「召唤伙伴」卡在已达 `maxCompanions` 时从池剔除。
- **卡牌池**（`skills.js`，当前 14 张，weight 均为 1）：

| id | 名称 | 效果（apply） | 类型 |
|----|------|--------------|------|
| `multi` | 连锁闪电 | `chainCount+1`（≤8） | 新技能 |
| `ats` | 急速射击 | `attackInterval×0.82` | 强化 |
| `dmg` | 伤害提升 | `damage×1.25` | 强化 |
| `spd` | 疾步 | `moveSpeed×1.12` | 强化 |
| `rng` | 射程扩展 | `range×1.15`（雷电链起手锁定射程） | 强化 |
| `prc` | 电弧扩散 | `chainRange×1.25`（每跳链长） | 新技能 |
| `shock` | 感电 | `slowOnHit+0.6s`（≤3，命中减速 50%） | 特化 |
| `storm` | 雷暴 | `aoeOnHit` 触发范围爆发（伤害 50%） | 特化 |
| `fork` | 分叉 | `fork+1`（每跳多锁 1 个目标） | 特化 |
| `leech` | 汲取 | `leech+0.12`（伤害回血，≤0.6） | 特化 |
| `hp` | 强健体魄 | `maxHp+25` 并治疗 25 | 强化 |
| `crit` | 暴击 | `critChance+0.1`（≤0.9，作用于雷电链 ×2） | 新技能 |
| `xp` | 经验精通 | `xpMult×1.2` | 强化 |
| `ally` | 召唤伙伴 | `game.addCompanion()` | 新技能 |

> **技能特化轴**：同招雷电链可按 `shock`(减速)/`storm`(范围)/`fork`(分叉)/`leech`(吸血)/`crit`(暴击)/`multi`(跳数)/`prc`(范围) 多方向进化，形成不同 build；这些字段初始为 0/未解锁，仅在拿到对应卡后生效（见 `config.player` 与 `player.castLightning`）。

## 7. 关卡与刷怪

- **刷怪间隔**：`max(minInterval(0.25), baseInterval(1.2) - (stage-1)×perStageReduce(0.14))`，每波 `burst`(1) 只。
- **波次推进**：`waveTimer` 每波 25s，归零 `nextWave`；超过 `count`(5) 波 → `win`；第 `companionFromWave`(3) 波起自动补 1 名伙伴。
- **难度爬升**：敌人 `maxHp`、`speed` 随关卡线性增长（见 `config.enemy`）。

## 8. 特效系统（`effects.js`）

纯 canvas 程序化绘制，全程 `globalCompositeOperation='lighter'` 出加色炫光，无需任何贴图。

| 能力 | 方法 | 说明 |
|------|------|------|
| 电火花/碎片 | `spark(x,y,color,{count,speed,life,size,gravity})` | 环形迸发粒子，可带重力 |
| 死亡碎裂 | `burst(x,y,color)` | 绿块 + 青白电火花四溅 |
| 锯齿闪电 | `bolt(ax,ay,bx,by,color,{segs,jitter,life,width})` | 折线 + 粗辉光 + 亮白芯，短暂淡出 |
| 屏幕震动 | `shakeAdd(mag,dur)` / `shakeOffset()` | 渲染时 `ctx.translate` 偏移 |
| 命中顿帧 | `hitStopAdd(d)` | `update` 中冻结实体、保留特效 |

**渲染分层**（`game.render`）：背景 → `save()+translate(震动)` → 敌人/子弹/伙伴/主角/移动指示 → `effects.draw`（特效盖在最上层）→ `restore()` → HUD（不受震动影响）→ 卡牌/结算覆盖层。

## 9. 美术资源管线

### 9.1 运行时加载（`assets.js`）
- **自适应泛洪去背景** `_removeBg`：从内缩 2-3px 的边缘取参考色，三重保护——
  1. 亮度下限（`lumFloor=120`）：深色描边/头发/靴子不算背景；
  2. 饱和度判据（`g-r>8 && g-b>8`）：绿色主导的角色（丧尸皮肤/外套）不被误删；米色底/蓝灰底都不触发；
  3. 与已接受邻居逐像素比色差（`edgeTol=16`）扩散，容忍背景渐变/暗角；透明比例 <30% 时告警。
- **加载方式**：
  - `loadSheet(name, src, frames, {raw:true})`：图片已是透明底（离线烘焙产物），直接用，不做像素处理；
  - `loadSheetGrid`：AI 多格图按列切片 → 每格包围盒裁剪 → **底对齐**拼成标准横条；
  - `loadProcessed`：单图去背景 + 可选清区域（去水印）。

### 9.2 离线烘焙（`tools/_bake.py`）—— 根治白底的根因
- **为什么离线**：运行时依赖 `wx.createCanvas`/`getImageData` 在开发者工具中行为不可靠，曾导致整张带底图被当作帧绘出（白底 bug）。
- **流程**：`remove_bg`（泛洪）→ 全局色键清除**封闭残留口袋**（手臂/腿间被阴影包围、泛洪进不去的区域，容差 45）→ 边界侵蚀清理过渡边 → 按列切片 + 包围盒 + 底对齐拼条 → 半分辨率（726×348）PNG 压缩。
- **产物**（已打包进 `assets/`）：
  - `zombie_walk.png`：4 帧走路循环条带（raw 加载，`drawZombie` 往返播放 `seq=[0,1,2,3,2,1]` 消除 4→1 跳变）；
  - `zombie.png`：静态透明兜底图（已弃用旧 JPEG 源）。
- **回退链**：`zombie_walk.png` → `zombie.png` → 矢量占位，缺图自动降级不白屏。

### 9.3 资源替换规范
- 放 `assets/hero.png` / `assets/ally.png` 即替换主角/伙伴矢量占位（`drawChibi` 自动识别）。
- 替换丧尸动画：按 `tools/_bake.py` 流程把横排 4 帧图烘焙为透明 PNG 覆盖 `zombie_walk.png` 即可。
- **向元宝出图要点**：纯色背景（推荐纯深蓝 `#10203a` 或纯灰，**勿用纯绿**——去底判据会吃掉绿色），横排同尺寸同位置多帧，无文字水印。
